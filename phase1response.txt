2. DATABASE SCHEMA, RLS & STORAGE MIGRATION
--------------------------------------------------------------------------------
File: `supabase/migrations/20260910000000_phase1_schema.sql`
- Tables Created:
  1. `profiles`: Extends `auth.users` with `role` enum ('citizen', 'admin'), full_name, phone, income, occupation, etc.
  2. `schemes`: Catalog table (name, category, jurisdiction, benefit, description, official_source, eligibility_status).
  3. `eligibility_rules`: Criteria rules (scheme_id, criterion_name, requirement, rule_type, evidence_source).
  4. `document_requirements`: Documents required per scheme (scheme_id, document_type, is_mandatory).
  5. `documents`: Uploaded citizen documents (citizen_id, document_type, file_path, status, confidence, extracted_fields JSONB).
  6. `applications`: Citizen scheme applications (citizen_id, scheme_id, status state machine, applicant_info JSONB, tracking_id).
  7. `application_documents`: Junction table linking applications to citizen documents.
  8. `agent_runs`: Multi-agent run sessions (citizen_id, input_query, status).
  9. `agent_events`: Granular multi-agent execution events (run_id, agent_name, action, details JSONB).
  10. `audit_logs`: Evidence and execution transparency logs (run_id, agent_name, action, evidence, result).
  11. `consent_records`: Citizen explicit data-sharing consents (citizen_id, application_id, shared_data, purpose, approved_at).
  12. `notifications`: In-app citizen notifications (citizen_id, title, body, type, is_read).

- Functions & Triggers:
  - `handle_new_user()` trigger: Automatically creates a `profiles` row upon `auth.users` insert.
  - `is_admin()` security definer function: Evaluates if current `auth.uid()` has `role = 'admin'`.

- Row Level Security (RLS):
  - Enabled on all 12 tables.
  - Citizen isolation: Citizens can only select/insert/update their own data (`citizen_id = auth.uid()` or `id = auth.uid()`).
  - Admin role bypass: Admin profile can inspect and manage all tables.
  - Schemes/rules: Public SELECT, Admin WRITE.

- Storage:
  - `documents` bucket configured (non-public).
  - Storage RLS policies enforce access isolation matching `storage.foldername(name)[1] = auth.uid()::text`.
